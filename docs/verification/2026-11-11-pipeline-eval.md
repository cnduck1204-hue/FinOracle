## 实验设置与局限

- **语料**（123 份）：金融监管总局“政策规章规范性文件”栏目 101 篇（按正文重排的 PDF，过滤了批复类），`feat/data-collection` 分支的 5 份官方版式 PDF，16 份由重排 PDF 栅格化（150 dpi JPEG）的模拟扫描件，1 份真实扫描件（银发〔2012〕178 号）。
- **问题**（164 道）：除真实扫描件的 11 道为人工标注外，其余由 qwen-plus 按原文条文生成，生成时不接触任何检索方案；官方 PDF 的条文与页码取自人工核对过的 release 数据。题型为改写提问（paraphrase）、关键词（keyword）和“《标题》第 X 条”（article）。
- **计分**：只看答案所在页是否被检索到（页级 Hit@1、Recall@5、MRR@10、nDCG@10），检索范围限定在同一语料的全部文档。配对 bootstrap 2000 次。
- **模型**：两个文本方案用 DashScope text-embedding-v4（1024 维）；两个视觉方案用 ColQwen2.5（vidore/colqwen2.5-v0.2，本机 RTX 3080 Ti）。延迟包含各自部署方式的网络开销，只作量级参考。
- **偏向说明**：问题从文字生成，article 题型直接点名标题与条号，天然有利于保留条号的文本方案；页级计分对按页检索的图片方案有利（文本方案即使定位到精确条文，也只按页计分）。扫描件题目只有 28 道（真实扫描件 11 道），置信区间较宽。
