# DeepSeek Harness 第一批接入计划

> 在当前会话按测试驱动逐项执行，并在验收前检查工作区差异。

**目标**　在 FinOracle 工作台提供可恢复的 `dsh` 制度问答、会话管理、历史召回和上下文压缩。

**架构**　FastAPI 与 MySQL 管理用户、会话和面向用户的经核验历史。独立的 `dsh` Host 执行模型循环和上下文压缩，并保存运行事件。FastAPI 使用轮次请求 ID 对接 Host，转发经核验的 SSE。

**约束**　保持既有会话 ID 和引用接口兼容。制度工具使用登录用户的本轮资料范围。部署配置只为问答加载所需工具，关闭 `dsh_session_log` 上传。

- [x] 后端会话列表、重命名、归档和按完整轮次分页。扩展 `chat_sessions` 模型、迁移、schema 和会话服务。验证账户隔离、中文搜索、固定历史游标和归档状态。
- [x] 工作台会话切换、历史搜索、加载旧轮次、归档和恢复。使用现有 API 客户端和问答样式，覆盖浏览器交互和类型检查。
- [x] 固定版本的 `dsh` 私有 Host、流式接口与轮次工具回调。验证同一请求 ID 去重、当轮证据校验、停止联动和段落落库。通过现有 `/chat/stream` 调用真实 DeepSeek 模型完成精确查条和引用核验。
- [x] 同会话上下文、旧会话续聊和显式跨会话引用。按原会话 ID 导入 `dsh` 缺少的有界制度定位线索。验证长会话压缩、重启续聊和跨账号隔离。
