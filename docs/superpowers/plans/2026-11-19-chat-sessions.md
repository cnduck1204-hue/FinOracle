# FinOracle 可恢复会话实现计划

以 MySQL 的有序会话事件作为工作台历史来源。当前由 `dsh` 恢复和压缩模型上下文，FastAPI 提供运行日志缺少的近期轮次线索，并逐段校验本轮证据。 [会话与流式设计](../specs/2026-11-19-llm-architecture-design.md#会话与记忆设计)

- [x] 创建迁移、会话仓储和归属校验。每轮写入提问及完成、失败或中断事件。每个会话同时只执行一轮，超期轮次可以恢复。
- [x] 接入会话创建和读取接口。SSE 发送会话及轮次 ID，最终答复提交后发送 `done`。对省略会话 ID 的提问自动创建会话。
- [x] 工作台从标签页恢复当前会话，展示多轮对话和中断状态，支持开始新会话。历史引用走现有详情接口。
- [x] 用真实 DeepSeek 测试第一条、刷新和第二条追问，回归会话归属、退出和停止生成。

本地工作台使用《中华人民共和国商业银行法》验证第一条、刷新后追问第二条以及打开第二条原文。已验证停止后刷新能恢复中断状态，漏收 `done` 时能取回已保存的回答。后端 887 项测试通过，1 项 OCR 测试因缺少可选依赖跳过。前端 60 项测试通过，生产构建通过。
