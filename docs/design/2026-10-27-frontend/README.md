## 页面流转

用户端：登录或注册 → 问答首页 → 答案与引用 → 制度原文。制度库与全文检索可以进入条文阅读，也可以携带制度或条号发起定向提问。历史与收藏均能返回原会话、制度和对应位置。

管理端：总览 / 制度文档 → 导入文件 → 导入任务 → 解析校验 → 发布预览与确认 → 用户可检索。用户反馈可回到原问题与引用版本，关联文档修订，再经校验发布生效。

管理员登录后也可使用用户端；账号菜单仅对管理员显示进入管理后台的入口。后台可以返回用户端，用户端保留原会话。

## 内容与交互规则

- **回答与原文同时可核查。** 桌面采用 232 px 导航、760 px 问答和 448 px 来源栏。点击 `[1]` 等引用定位原文，保留制度名称、条号、页码、收录版本、发布机关和来源网址。
- **收录版本与时效分开。** 原文、列表、检索结果、答案和收藏共用同一版本标识。待核验不展示为已确认有效。资料更新后，历史答案保留原引用版本，提示可基于新版本重新提问。
- **问答状态可恢复。** 查找依据与生成中提供停止；停止后已有内容标记为未完成。错误时保留问题与部分回答，重试沿用会话。依据不足明确说明并提供缩小范围或补充场景入口，不生成无依据的确定结论。
- **引用不可访问时解释原因。** 下架或失去权限后，不继续显示受限原文；历史会话保留出处标识并提示当前不可访问。
- **导入与发布分别管理。** 上传成功、解析完成、索引准备、校验通过、版本发布是不同状态。草稿不进入用户检索；发布前预览版本和影响范围并确认。修订创建草稿，不能直接改写已发布版本。
- **失败可定位。** 导入列表和任务详情显示失败阶段与页码，提供重新识别或替换文件入口；重试复用任务，处理中阻止重复提交。
- **危险操作有具体确认。** 删除会话、全部退出、禁用用户、强制下线、下架及发布替换都展示目标和影响范围。普通用户资源归本人；管理员入口与操作必须由服务端校验。
- **两级角色。** 仅普通用户和管理员；不引入自定义角色、多租户或自助提权。管理员账号不提供禁用入口。注册仅创建普通用户。
- **认证沿用现有能力。** 用户名或邮箱登录；用户名 3–32 位字母、数字或下划线；密码至少 8 位且含字母数字；注册确认密码一致。未提供找回密码、第三方登录或管理员自助注册。
- **资料分阶段开放。** 当前资料查询可用；编辑用户名和邮箱待后端实现后启用。角色、状态保持只读。
- **列表可扩展。** 制度、任务、用户、会话和反馈列表均保留搜索、筛选、分页与空态。返回列表恢复筛选和位置；当前线框展示少量示例行，分页在结果超过一页时出现。
- **反馈闭环。** 反馈携带问题、答案和引用版本，管理员记录处理结论；修订资料经发布后用于后续问答，不覆盖原回答快照。

## 视觉与适配

桌面画幅 1440 × 900，正文黑色、白底，普通边框 1 px，选中项与主要操作边框 2 px。页面标题 30 px、主要内容 17–22 px、辅助内容 14–16 px。不依赖颜色区分状态，以文字、描边和位置表达。

≥1280 px 保留三栏；768–1279 px 使用来源抽屉；<768 px 使用单栏、收起导航和独立原文页。移动端输入区跟随键盘保持可见，返回引用前的位置；用户端表格转信息卡，后台表格可以横向滚动。触摸目标至少 44 px，键盘焦点可见，抽屉关闭后返回引用按钮焦点。
